# Mirth Graph

Mirth Graph is a web application that uses force graphs to visualise a Mirth's channels, source connectors and destinations.

# README (v0.1.0)

Setup is simple:

1. `git clone https://github.com/NicoPiel/mirthgraph`
2. `cd mirthgraph`
3. `git checkout feature/frontend-rewrite`
4. `pnpm install`
5. `pnpm dev --host`

If necessary, it may help to add your host FQDN to `allowedHosts` in `vite.config.ts`.
